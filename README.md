Flutter Calculator App
A simple, clean calculator built with Flutter, featuring a dark-themed iOS-style interface.
Features

Basic arithmetic operations: addition, subtraction, multiplication, and division
Percentage calculation
Positive/negative toggle (+/-)
Decimal point support
Auto-formats results (removes unnecessary decimals)
Reset via AC button

Tech Stack

Framework: Flutter (Dart)
UI: Custom styled ElevatedButton with circular and stadium shapes
Theme: Dark mode (black background, amber operators, grey numbers)
